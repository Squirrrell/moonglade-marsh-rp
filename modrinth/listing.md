# Modrinth upload fields

## Create project (modrinth.com → "+" → Create a project)
| Field | Value |
|---|---|
| Name | Custom Moonglade Marsh |
| URL / slug | `custom-moonglade-marsh` |
| Visibility | Public (or Unlisted to test first) |
| Summary | Configurable Catharsis recolour pack for Moonglade Marsh: fig and mangrove trees, grass and clutter. |

## Project settings
| Field | Value |
|---|---|
| Project type | Resource Pack |
| Icon | `Moonglade Marsh/pack.png` |
| Description | contents of `modrinth/description.md` |
| Categories | Decoration (or Tweaks), plus resolution `16x` |
| Environment | Client-side |
| License | Your choice. Note that the textures are recoloured vanilla textures, not original art. |
| Gallery | your in-game screenshots (the light-blue fig and red mangrove shots work well) |
